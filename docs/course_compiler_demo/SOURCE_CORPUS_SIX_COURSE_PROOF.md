# Source Corpus Six-Course Proof

The Wave 066 synthesis pipeline compiles six reference course corpora from 18
clearly labeled, AxiomIQ-authored internal fixtures. The population includes
the required PDF, syllabus, standards, question-bank, and course-definition
source classifications without claiming that a fixture is an external
authoritative curriculum.

For every course, the pure pipeline produces a normalized corpus, evidence
graph, extracted and synthesized curriculum packages, preserved conflict and
coverage reports, proposed nonauthoritative mappings, a 300-question generation
manifest, proposed assessment blueprints, and a quality-review package. The
compiler does not generate questions, assign canonical authority, write a
database, contact an adaptive platform, or expose student-visible content.

Checkpoint and reopen validation hashes the complete result and verifies the
same deterministic hash after a fresh rebuild.
