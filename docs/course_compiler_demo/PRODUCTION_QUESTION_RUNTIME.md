# Production Question Runtime

This offline runtime produces deterministic, nonfixture, noncanonical question
candidates from registered subject-pack families. Candidate generation and
independent derivation are separate interfaces. Every locked bank requires
answer agreement, procedure and failure-signal compatibility, prompt
determinacy, unit/tolerance checks, fingerprints, duplicate analysis, family
review, and a twenty-instance review sample.

Outputs remain human-review-required, non-student-visible, ineligible for Alpha
import, and unauthorized for canonical promotion or database writes.
