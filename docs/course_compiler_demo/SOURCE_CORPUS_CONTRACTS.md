# Source Corpus Contracts

The `source_corpus.contracts` package defines strict, deterministic, version-one
records for source documents, normalized segments, asset references, rights,
evidence claims and links, extracted candidates, synthesis nodes, conflicts,
coverage gaps, packages, and review decisions.

Every supported curriculum item carries source identity, SHA-256, location,
segment, extraction method, confidence, review state, and rights classification.
Synthesis and prerequisite inference require evidence and rationale. Unsupported
material is explicit. These records are noncanonical, student-data-free, and
cannot grant database, adaptive-platform, publication, or canonical authority.
