# Programming Fundamentals Reference Pack

This noncanonical, review-required pack covers variables, control flow, functions, collections, strings, I/O, exceptions, testing, debugging, recursion, and basic complexity. It supplies eight units, 25 topics, 50 micro-skills, 15 procedures and parameterized generation families, two assessment blueprints, and a 300-question validation target. Code contracts include I/O and unit-test descriptors, while `code_execution` remains explicitly unsupported and cannot execute.
