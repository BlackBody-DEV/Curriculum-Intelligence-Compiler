# Mathematics Reference Pack

This deterministic, noncanonical reference pack describes Algebra I and Calculus I for compiler generation planning. Each course includes at least eight units, 25 topics, 50 micro-skills, 15 procedures, 15 parameterized generation families, prerequisite relationships, difficulty and failure-signal allocations, and two assessment blueprints targeting 300 validated questions.

The pack is `human_review_required`; it makes no canonical claim and contains no student-performance data.
