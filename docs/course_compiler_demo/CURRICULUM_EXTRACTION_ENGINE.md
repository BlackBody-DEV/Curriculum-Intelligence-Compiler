# Curriculum Extraction Engine

The deterministic engine extracts fifteen labeled curriculum target types from syllabus, textbook-style, standards, question-bank, and course-package sources. Every candidate points to one or more provenance-resolved evidence claims with source hash, segment, location, extraction method, confidence, rights, and review state. Duplicate labels aggregate evidence; unrecognized material is reported explicitly as unsupported.

Question-bank extraction preserves prompt, answer, optional solution, question/answer types, curriculum/difficulty/procedure hints, and asset references. Every extracted question remains noncanonical, unvalidated, human-review-required, and incapable of granting canonical authority.
