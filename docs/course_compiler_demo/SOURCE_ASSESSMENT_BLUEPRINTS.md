# Source assessment blueprints

Exactly four strict blueprint types are supported: practice, diagnostic, formative, and summative. Every blueprint requires complete topic/difficulty/question-type distributions, unit and skill scope, assessment objectives, generation families, grading engines, source examples, prerequisite and source-evidence coverage, reuse and variant policies, scoring, rubrics, and compiler-review approval. Unsupported objectives, missing generation families or grading engines, inconsistent topic weights, insufficient curriculum coverage, impossible time budgets, course mismatches, cross-course dependencies or examples, unresolved evidence, and source conflicts are blocking. Valid records project into `AssessmentBlueprintV1`; they remain proposed and reviewable and do not generate questions or authorize canonical, database, adaptive-platform, or student-visible activity.
